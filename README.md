# Multivariable Calculus Manipulatives

This repository contains materials associated with the manuscript "[Promoting active learning, collaboration, and visualization: manipulatives for proof-based multivariable calculus at scale](https://www.math.toronto.edu/qiu/writings/MultivarCalcManipulatives.pdf)" by Yuzhe Liu, Sydney Pinkalla, [Arthur Lei Qiu](https://www.math.toronto.edu/qiu/), and [Asif Zaman](https://www.math.toronto.edu/zaman/). This manuscript summarizes the outcomes of a teaching project to develop manipulative-based lessons for MAT237 (*Multivariable Calculus with Proofs*), a large, proof-based multivariable calculus course for second-year undergraduate science students at the University of Toronto. Included in this repository are:

- Student-facing worksheets and slides for five manipulative-based lessons run during the 2024-2025 and 2025-2026 offerings of MAT237. Only the updated 2025-2026 versions of these materials are included.
- Instructions for manufacturing the three types of manipulatives used in these lessons (3D printed graph, wooden wedge, foam bead).

The materials in this repository are licensed under <a href="https://creativecommons.org/licenses/by/4.0/">CC BY 4.0</a>. Instructors wishing to adapt these materials for their own use may contact [Asif Zaman](https://www.math.toronto.edu/zaman/) to request editable LaTeX source files and instructor-facing materials such as teaching guides for each lesson.
