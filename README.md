# Multivariable Calculus Manipulatives

This repository contains materials associated with the manuscript "[Promoting Active Learning, Collaboration, and Visualization: Manipulatives for Proof-Based Multivariable Calculus at Scale](https://www.math.toronto.edu/qiu/writings/MultivarCalcManipulatives.pdf)" by Yuzhe Liu, Sydney Pinkalla, [Arthur Lei Qiu](https://www.math.toronto.edu/qiu/), and [Asif Zaman](https://www.math.toronto.edu/zaman/). This manuscript summarizes the outcomes of a teaching project at the University of Toronto to develop manipulative-based lessons for proof-based multivariable calculus courses. Included in this repository are:

- Student-facing worksheets and slides for five manipulative-based lessons run during the 2024-2025 and 2025-2026 offerings of MAT237 (*Multivariable Calculus with Proofs*), a second-year undergraduate mathematics course at the University of Toronto. Only the updated 2025-2026 versions are included.
- Instructions for manufacturing the three types of manipulatives used in these lessons (3D printed graph, wooden wedge, foam bead).
